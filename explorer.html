Méthode douce

Explorer sans se perdre dans l'histoire.

L'exploration doit rester claire. Voici un fil simple à suivre lorsque vous utilisez les outils.

01

Nommer

Choisissez une situation précise : ce qui revient, ce qui bloque, ce qui vous touche.

02

Observer

Regardez ce que votre corps, vos émotions et vos réactions racontent.

03

Relier

Cherchez les échos dans la famille : dates, destins, places, absences, silences.

04

Noter

Gardez les indices sans conclure trop vite. Une carte se révèle toujours par étapes.

Après l'exploration

Ce que vous découvrez mérite parfois d'être accompagné.

Les outils ouvrent des pistes. Une séance permet de les approfondir, de les relier et d'avancer avec un regard extérieur.

Être accompagné

Si les indices se répètent

Notez les dates, les âges, les prénoms, les situations qui reviennent.

Si le corps réagit fort

Ralentissez. L'exploration n'est pas une enquête à forcer.

Si une émotion surgit

Elle peut être une messagère. Accueillez-la avant de chercher à l'expliquer.

Si tout devient flou

Revenez au point de départ : une situation, une question, une sensation.

La carte ne donne pas toutes les réponses.
